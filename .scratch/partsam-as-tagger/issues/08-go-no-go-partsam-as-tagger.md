# 08 - Go/no-go: PartSAM as the lasting Material Tag Tensor source

Type: grilling
Status: resolved
Blocked by: 01, 05, 06, 07

## Question

Is PartSAM the **lasting** intended producer of the Material Tag Tensor, or do we **leave the ficus trial as a trial**?

The trial **passed** ingest + 5-frame survival ([RESULT.md](../../partsam-ficus-trial/RESULT.md)). That is not this bar. **NO** if any of: `partfield/` NVIDIA non-commercial blocks intended GitHub/academic use; the generic seam still needs a human to place clicks every scene; inference depends on unreproducible stubs as the official path; overlap policy cannot be stated without another trial.

This ticket is the go/no-go only. What happens to Heuristic Primitives / Segmenter Agent / FlashSplat / LangSAM is [What happens to the current Material Tag Tensor producers](09-current-taggers-if-yes.md).

## Answer

**YES.** PartSAM is the lasting intended producer of the Material Tag Tensor. A later map wires `src/`; this map writes the spec.

None of the four standing NO bars fired: NVIDIA `partfield/` allows public academic GitHub if PartSAM is gitignored upstream ([NVIDIA-noncommercial partfield vs this repo's intended use](01-partfield-license-vs-intended-use.md)); the happy-path click seam is geometry + MLLM, not a human every scene ([Click path for the generic PartSAM recipe](05-click-path-generic-recipe.md)); overlap is highest chosen-mask predicted IoU ([Overlap and merge policy without another trial](06-overlap-merge-policy.md)); the supported three-click path is the in-repo PyTorch FPS stand-in, not claimed as PartSAM-official ([May the documented inference path use the trial stubs](07-documented-inference-stubs.md)).

The ficus trial pass is not this bar. Leftover caveats (oversized trunk, ficus-only evidence, academic-only NVIDIA grant, local FPS stand-in) stay as spec constraints, not a leave-as-trial.

Heuristic Primitives / Segmenter Agent / FlashSplat / LangSAM are [What happens to the current Material Tag Tensor producers](09-current-taggers-if-yes.md).
